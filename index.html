Networking Overview

Zero-Configuration NAT Traversal

MeshCentral establishes secure bidirectional communication loops over standard HTTPS. No firewalls need to be opened, and no dynamic DNS configured for local networks.

  • 1

    Lightweight Agent Connection

    The client MeshAgent initiates an outbound secure WebSocket connection back to the self-hosted MeshCentral server over standard HTTPS port 443.

  • 2

    Secure Persistent Tunnel

    The connection is upgraded to a persistent TLS WebSocket. The server maps the device behind any standard NAT, gateway, or home firewall without configuration.

  • 3

    technician Web Access

    The administrator logs into MeshCentral from any browser. Remote desktop commands, terminal signals, and files flow inside the WebSocket tunnel seamlessly.

Single Command Deployment

Launch a secure, production-grade remote management node in less than two minutes. Choose your configuration below.

NPM Setup
Docker Container
NPX Instant Run
# Install MeshCentral globally
npm install -g meshcentral

# Run the installation service Setup
node node_modules/meshcentral
# Pull and launch official MeshCentral container
docker run -d \
  --name=meshcentral \
  -p 80:80 -p 443:443 \
  -v meshcentral-data:/meshcentral/meshcentral-data \
  -v meshcentral-files:/meshcentral/meshcentral-files \
  ghcr.io/ylianst/meshcentral:latest
# Run instant sandbox node without installing
npx meshcentral --port 8080 --launch
